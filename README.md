# PRShowcase

Turns GitHub pull requests into portfolio pages.

## Features

- PR-based portfolio generation

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/pr-artist-portfolio.git
cd pr-artist-portfolio
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
